# myHDVBlog — חיים בקצב שלי 🧠💛

בלוג ווולוג אישי בעברית — על החיים והיומיום של אמא לארבעה, עובדת במשרה מלאה, עם הפרעת קשב וריכוז (ADHD).

## מה יש באתר

- ✍️ **בלוגים יומיים** — "איך עבר עליי הבוקר"
- 🎬 **וולוגים** — הטמעת סרטוני YouTube, פייסבוק או קובץ וידאו
- 📸 **תמונות** — קישור או העלאה מהמכשיר
- 🔗 **קישורים חיצוניים** — כל קישור אחר מוצג ככפתור צפייה
- 💡 **בקשות טיפים** — מהקהילה, עם תגובות
- ❤️ לייקים ותגובות לכל פוסט
- 💾 פוסטים, המלצות והקישור המומלץ נשמרים בענן ב-Supabase
- 🔒 רק בעלת הבלוג יכולה לערוך את הקישור המומלץ, לאחר כניסה
- ❤️ לייקים אישיים נשמרים מקומית בדפדפן (localStorage)
- 📤 כפתור שיתוף לכל פוסט (וואטסאפ/פייסבוק/העתקת קישור)
- 👁️ מונה כניסות לאתר — גלוי רק לבעלת הבלוג במצב עריכה
- 🔍 מותאם לגוגל (SEO) ולשיתוף ברשתות (Open Graph, sitemap.xml)

## איך מריצים

פשוט פותחים את `index.html` בדפדפן, או משתמשים בתוסף **Live Server** ב-VS Code.
כדי להפעיל שמירה של הקישור המומלץ, הריצי את `supabase-setup.sql` ב-Supabase SQL Editor.
כדי להפעיל את מונה הכניסות, הריצי שוב את `supabase-setup.sql` (החלק של `page_views` בסוף הקובץ).

## איך מעלים לאינטרנט (חינם)

כדי שיהיו לך קוראים אמיתיים, אפשר לפרסם בקלות:

- **GitHub Pages** — העלי את הריפו ל-GitHub ← Settings ← Pages ← בחרי branch
- **Netlify / Vercel** — גרירה של התיקייה וזה באוויר

## התאמה אישית

- שם האתר, הכיתובים והטקסט "קצת עליי" — ב־`index.html`
- הצבעים והעיצוב — ב־`css/style.css` (משתני `:root` בראש הקובץ)
- הפוסטים לדוגמה — ב־`js/script.js` (מערך `samplePosts`)
